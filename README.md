# SWYNEX - Biological Dataset Selection

## 1. Project Title
Gene Expression Profiling in Breast Cancer**

## 2. Introduction
This project focuses on selecting a publicly available biological dataset to study gene expression patterns associated with breast cancer.

## 3. Dataset Information
Repository: NCBI Gene Expression Omnibus (GEO)
Accession Number: GSE139038
  Dataset URL:https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE139038
  Organism:Homo sapiens (Human)
  Data Type: Gene expression microarray
  Sample Size: 65 samples

## 4. Research Question
Which genes show different expression patterns between breast tumour tissue and normal breast tissue?

## 5. Objectives
1. Select a public biological dataset.
2. Document its source, size, and data type.
3. Define a biological research question.
4. Describe its potential application in bioinformatics.

## 6. Dataset Description
The dataset includes breast tumour tissue, paired normal tissue, and apparently normal breast tissue samples. These samples can be investigated to understand differences in gene expression.

## 7. Proposed Methodology
1. Access the dataset from NCBI GEO.
2. Review the study description and sample annotations.
3. Examine the gene expression data.
4. Compare appropriate tumour and normal groups using statistical methods.
5. Identify potential differentially expressed genes.

## 8. Biological Significance
Gene expression analysis may help researchers investigate breast cancer-associated genes and potential biomarkers for further research.

## 9. Expected Outcome
A documented public dataset with a clearly defined research question and a proposed gene expression analysis workflow.

## 10. Limitations
This project covers dataset selection and documentation only. Further computational analysis and independent validation are required to draw biological conclusions.
